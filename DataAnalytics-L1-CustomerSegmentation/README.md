# Task 2: Customer Segmentation Analysis

## Objective
Group customers into distinct clusters using RFM (Recency, Frequency, Monetary) metrics to support targeted marketing campaigns.

## Workflow
- RFM feature extraction from transactional data
- Data standardization using StandardScaler
- Optimal cluster identification using the Elbow Method
- K-Means clustering and behavioral segment profiling

## Tech Stack
`Python` `Pandas` `Scikit-learn` `Matplotlib` `Seaborn`
