# Task 3: Data Cleaning Pipeline

## Objective
Build a structured data cleaning pipeline to handle imperfect raw datasets and prepare them for production analytics.

## Workflow
- Missing value diagnosis and median/mode imputation
- Type casting and string normalization
- Duplicate row identification and deduplication
- Outlier detection and capping using the IQR method

## Tech Stack
`Python` `Pandas` `NumPy`
