# Task 4: Sentiment Analysis on Social Media Data

## Objective
Build and evaluate Natural Language Processing (NLP) models to categorize tweets into Positive, Negative, and Neutral sentiments.

## Workflow
- Text preprocessing (lowercasing, stopword removal, lemmatization)
- Feature extraction using TF-IDF Vectorization
- Model training: Multinomial Naive Bayes & Logistic Regression
- Performance evaluation using classification reports and confusion matrices

## Tech Stack
`Python` `Pandas` `NLTK` `Scikit-learn` `Matplotlib`
